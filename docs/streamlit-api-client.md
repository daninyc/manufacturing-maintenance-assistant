# Streamlit 调试入口迁移

ui/streamlit_app.py 不再导入 Chroma 或直接调用旧问答服务，只通过 ui/api_transport.py 请求鉴权 API。先配置 MAINTENANCE_API_URL 为可信 HTTPS 根地址，再运行 Streamlit。不要把密码、token 或 DeepSeek Key 写入 URL；不支持 HTTP 或自动跟随重定向。

登录请求交给后端，页面每次重绘先验证 /me。问答调用 /api/v1/ask；保留回答再次显示之前，逐条调用鉴权引用接口，要求策略版本、内容版本和原文匹配。任一引用无法验证则清空整份回答。退出立即清理本地状态，再尝试撤销服务器会话；离线时明确提示撤销未确认。

页面迁移测试使用 API 替身，覆盖未配置服务器、未登录、登录、正常问答与引用撤权清理；与受保护问答测试合计 14 passed（11.73 秒，2 条已有警告）。原型号比较题转为直接调用旧服务的离线基线测试，保留其可回答和双来源断言。未做真实 HTTPS Streamlit 联调，也不声称已完成对所有 CLI 调试入口的部署隔离。

此页面用于开发调试与管理验收；当前客户端交付目标仅为 Windows。已经显示、复制或截图的内容无法被撤权远程收回；页面重绘和再次请求才重新验证。
